# About ClotCor

## Purpose

ClotCor is designed to make predictive crime analysis understandable for non-technical users, including:

- beginners,
- senior users,
- analysts without machine learning background.

## Design Goals

1. **Usability first**
   - guided UI flow,
   - plain-language labels and explanations,
   - direct answers for common decision questions.

2. **Statistical rigor**
   - leakage detection,
   - temporal validation split,
   - probability calibration.

3. **Operational relevance**
   - future risk by area and date,
   - predictive hour/day heatmaps,
   - top-area ranking for selected crime.

## What ClotCor Is Not

- It is not a certainty engine.
- It does not guarantee events.
- It should not be used as the only source for critical legal/safety decisions.

Use it as a decision-support tool combined with human judgment and domain knowledge.
